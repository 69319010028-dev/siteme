📤 กู้คืนข้อมูลจากไฟล์สำรอง (Import / Restore)

นำเข้าไฟล์ .json ที่เคยสำรองไว้

เลือกไฟล์ .json ที่เคยดาวน์โหลดไว้ ระบบจะตรวจสอบความถูกต้องและกู้คืนข้อมูลใบงาน, โปรไฟล์, แบนเนอร์ และประวัติการศึกษากลับมาทั้งหมด

คลิกเพื่อเลือกไฟล์สำรอง (.json) หรือลากไฟล์มาวางที่นี่ รองรับเฉพาะไฟล์ .json ที่ส่งออกจากระบบนี้เท่านั้น
✅ ตรวจพบข้อมูลสำรองที่ถูกต้อง พร้อมกู้คืน:

🕒 จุดสำรองข้อมูลด่วนในเครื่อง (Local Snapshots)

ยังไม่มีจุดสำรองข้อมูลด่วน กดปุ่ม "บันทึกจุดสำรองเดี๋ยวนี้" เพื่อบันทึกสถานะปัจจุบันไว้ในเบราว์เซอร์

☁️ ระบบซิงค์ข้อมูลคลาวด์แบบเรียลไทม์ (เหมือน Google Sites)

แก้ปัญหาแชร์ลิงก์ให้คนอื่นแล้วยังเห็นเป็นเว็บเดิม ด้วยการเชื่อมต่อ Google Cloud (Firebase) ข้อมูลจะอัปเดตตรงกันทุกคนทันทีใน 1 วินาที!

☁️
🟡 โหมดโลคอล (ยังไม่ได้เชื่อมต่อ Google Firebase Cloud)
เมื่อเชื่อมต่อแล้ว ไม่ว่าจะแก้ไขใบงาน รูปภาพ หรือเกรดเฉลี่ย ทุกคนที่เปิดลิงก์ Vercel จะเห็นข้อมูลอัปเดตสดทันทีโดยไม่ต้อง Export
💡 วิธีตั้งค่า Google Firebase ให้เว็บเป็นเรียลไทม์ (ฟรี 100% ตลอดชีพ):
1. สร้างโปรเจกต์

เข้า console.firebase.google.com ด้วยบัญชี Google แล้วกด "Add project" ตั้งชื่อเว็บของคุณ

2. เปิดฐานข้อมูล Firestore

ไปที่เมนูซ้าย "Build" ➔ "Firestore Database" กด "Create database" แล้วเลือก "Start in test mode"

3. สร้าง Web App

กดรูปฟันเฟือง ⚙️ Project settings ด้านบนซ้าย เลื่อนลงมากดปุ่ม `</>` (Web) แล้วก๊อปปี้โค้ด firebaseConfig

4. นำมาวางที่นี่

นำโค้ดที่ได้มาวางในช่อง "วางโค้ด firebaseConfig" ด้านล่างแล้วกดปุ่มบันทึก ระบบจะเชื่อมต่ออัตโนมัติ!

⚙️ กำหนดค่าเชื่อมต่อ Firebase Configuration

📥 อัปเดตไฟล์ต้นฉบับ data.js (สำหรับอัปโหลดขึ้น GitHub/Vercel)

หากคุณไม่ต้องการใช้ระบบคลาวด์ คุณสามารถกดปุ่มนี้เพื่อดาวน์โหลดไฟล์ data.js ที่มีข้อมูลปัจจุบันทั้งหมด (รูปจริง, เกรด 3.88, ใบงาน 3 รายการ) แล้วนำไฟล์นี้ไปวางทับในโฟลเดอร์ js/data.js แล้วอัปขึ้น GitHub หรือ Vercel เว็บไซต์ก็จะเปลี่ยนข้อมูลเริ่มต้นให้ทุกคนทันทีครับ!
